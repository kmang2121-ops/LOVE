# การ์ดบอกรัก 💐

เว็บหน้าเดียว — การ์ดบอกรักใบเดียวกลางจอ สีชมพูอ่อน มีแมวถือช่อดอกไม้อยู่ตรงกลาง สำหรับส่งลิงก์ให้แฟนเปิดอ่าน

สร้างด้วย Next.js + Tailwind **ไม่มีฐานข้อมูล ไม่มี API ไม่ต้องล็อกอิน** เป็นหน้า static ล้วน เปิดแล้วจบในเบราว์เซอร์

## การ์ดทำอะไรได้บ้าง

| อย่าง | รายละเอียด |
|------|-----------|
| **คำบอกรัก 5 ใบ** | ปุ่มชมพู "รักเหมือนกัน" อยู่ที่เดิมตลอด กดเมื่อไหร่ก็จบ ส่วนปุ่มจาง ๆ ข้างล่างแปลว่า "พูดอีกที" กดแล้วเปลี่ยนใบ |
| **แตะแมวเล่นได้** | หัวใจเด้งตรงนิ้ว แมวสะบัดตัว และมีคำพูดใต้ภาพที่เขินขึ้นเรื่อย ๆ ตามจำนวนครั้งที่แตะ |
| **หน้าตอบรับ** | ปล่อยหัวใจเต็มจอ พร้อมข้อความตอบกลับสำเร็จรูปที่แตะแล้วคัดลอกไปวางในแชทได้ |
| **ใส่ชื่อในลิงก์** | `/?to=ชื่อเขา&from=ชื่อเรา` ไม่ใส่ก็ใช้ชื่อเล่นที่ตั้งไว้ใน `lib/rak.ts` |

## แก้ข้อความเองได้ตรงไหน

ข้อความทุกคำอยู่ใน [`lib/rak.ts`](lib/rak.ts) ที่เดียว แก้ได้โดยไม่ต้องอ่าน JSX

| ตัวแปร | คืออะไร |
|--------|---------|
| `DEFAULT_TO` / `DEFAULT_FROM` | ชื่อเล่นที่ใช้เมื่อไม่ได้ใส่ชื่อมาในลิงก์ |
| `LOVE_STEPS` | คำบอกรักทั้ง 5 ใบ (หัวข้อ, เนื้อความ, ข้อความบนปุ่มจาง ๆ, สีหน้าแมว) |
| `THANKS` | หน้าตอบรับหลังกดปุ่มชมพู |
| `REPLIES` | ข้อความตอบกลับสำเร็จรูป |
| `petLine()` | คำพูดตอนโดนแตะ เปลี่ยนตามจำนวนครั้ง |

ใน `LOVE_STEPS` และ `THANKS` เขียน `{to}` กับ `{from}` แทนชื่อได้ ระบบจะเติมชื่อจริงให้เอง

## เปลี่ยนรูปแมว

วางไฟล์ทับ [`public/cat-rose.webp`](public/cat-rose.webp) ได้เลย ไม่ต้องแก้โค้ด — ใช้รูป**จัตุรัส พื้นขาว** จะเข้ากับกรอบที่สุด (ของเดิม 480×480)

รูปนิ่งเปลี่ยนสีหน้าตามคำพูดไม่ได้ อารมณ์ของแต่ละใบจึงสื่อด้วยสติกเกอร์มุมกรอบแทน (ตั้งค่าได้ที่ `STICKERS` ใน [`components/Mascot.tsx`](components/Mascot.tsx)) และแตะแล้วแมวสะบัดตัว

> ⚠️ รูปที่ให้มาเป็นมีมที่มีคนวาดไว้ก่อน ใช้ส่วนตัวไม่มีปัญหา แต่ถ้าจะเอาไปใช้เชิงพาณิชย์หรือทำให้เป็นสาธารณะวงกว้าง ควรเปลี่ยนเป็นรูปที่วาดเอง

## รันในเครื่อง

```bash
npm install
npm run dev      # เปิด http://localhost:3000
```

คำสั่งอื่น: `npm run build` (สร้างของจริง), `npm start` (รันของจริง), `npm test` (เทสต์), `npm run lint`

## ขึ้น Vercel

1. push repo นี้ขึ้น GitHub
2. เข้า [vercel.com](https://vercel.com) → **Add New… → Project** → เลือก repo นี้
3. กด **Deploy** — ไม่ต้องตั้ง environment variable อะไรเลย เพราะเว็บนี้ไม่ต่อกับอะไรทั้งนั้น

เสร็จแล้วจะได้ลิงก์หน้าตาแบบ `https://<ชื่อโปรเจกต์>.vercel.app` ส่งให้เขาได้เลย

## กติกาที่ตั้งใจให้เป็นแบบนี้

- **ไม่บังคับให้ตอบ** ปุ่มจาง ๆ แปลว่า "พูดอีกที" ไม่ใช่ "ยังไม่ตอบ" และใบสุดท้ายบอกว่ากดตอนไหนก็ได้ที่พร้อม
- **ไม่มีปุ่มส่งที่ส่งไปไม่ถึงใคร** เว็บนี้ไม่มีเซิร์ฟเวอร์ คำตอบกลับจึงเป็นการคัดลอกไปวางในแชท และเขียนบอกไว้บนจอตรง ๆ
- **ชื่ออยู่ในลิงก์เท่านั้น** ไม่ได้เก็บที่ไหน และถูกล้างอักขระควบคุม/ตัวสลับทิศอ่านก่อนขึ้นจอ เพราะค่าที่มาจากลิงก์เชื่อไม่ได้
- **เคารพการตั้งค่า "ลดการเคลื่อนไหว"** ของเครื่อง — หัวใจกับแมวจะหยุดนิ่งให้เอง
